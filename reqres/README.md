# reqres — Pruebas de API

Pruebas funcionales sobre https://reqres.in/api/.

## Alcance

- `POST /api/users` con `{"name": "Test User", "job": "Automation Engineer"}` → HTTP 201.
- Extraer el `id` de la respuesta.
- `GET /api/users/{id}` → HTTP 200, con el nombre y el trabajo enviados en el POST.
